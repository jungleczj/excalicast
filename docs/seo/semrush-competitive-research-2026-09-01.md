## 3. 外链信号

Loom 反向链接快照：Authority Score 63、约 85K 引荐域名、4.43M 反链；Follow 57%、Nofollow 43%，文本链接约 85%。来源类别以知识、计算机软件与开发、在线服务、IT、广告营销为主。主要锚文本大量是裸 URL、品牌 `loom` 与具体视频分享链接，而不是人工堆砌精确匹配关键词。

对 Excalicast 的可执行结论：

1. 让每个公开分享视频、嵌入和模板都具备可选择的归因链接，但默认尊重隐私与 noindex。
2. 发布真实技术说明：操作流与像素录制差异、浏览器本地数据边界、Autozoom 编辑模型。
3. 向教师、设计系统、架构与异步协作社区提供可引用的模板或研究，而不是买 PBN。
4. 用竞品 Backlink Gap 找“同一域名已链接 2–3 家竞品但未链接 Excalicast”的编辑型站点。
5. 通过 broken-link replacement、客座案例、记者请求和产品目录获取相关链接；付费合作必须标注 sponsored/nofollow。

## 5. 指定 YouTube 视频：采用项与遗漏项

视频：[`Claude Code SEO: How I Got 50,000 Clicks Per Month (Steal This)`](https://www.youtube.com/watch?v=4IyJm1i__ag&t=234s)。

### 应采用

- 用 SEMrush 找真实词，不让 LLM 猜流量。
- 信息词博客建立主题权威，服务/比较页承接转化。
- 一个页面一个主词，辅词形成语义集群。
- 分析非 Reddit Top 3 的字数、H2、图片与结构。
- 加入品牌声音、经验、观点、数据和故事，避免 AI 套话。
- 同时做 on-page、技术 SEO、Lighthouse、sitemap、Search Console 与外链。
- 不批量倾倒 1,000 篇 AI 文，不使用 PBN、链接农场或廉价垃圾外链。

### 视频遗漏或需要修正

1. **搜索意图重叠/关键词内耗：** 视频偏“一词一页”，但 Windows 三个词 SERP 高度同质，应聚成一页。
2. **产品真实性：** 排名结构不能替代真实能力。Excalicast 不是逐帧角色动画器，也不能把普通屏幕采集说成结构化操作流。
3. **信息增益：** 仅“仿 Top 3 格式”仍会同质化；必须增加对比实验、原创截图、真实成片、故障边界和可引用事实。
4. **E-E-A-T 与更新责任：** 教程应有作者、核验日期、官方来源和版本变化说明。
5. **国际化：** Excalicast 有中英双语，需要独立关键词验证、hreflang 与非直译内容，而不是只复制英文集群。
6. **转化测量：** 排名不是终点；需要 `organic_landing_view → content_cta_click → recording_setup_open` 漏斗与按页面归因。
7. **索引预算与质量门槛：** 模板页/UGC 只有在有独特内容、隐私许可和内部链接时才开放索引。
8. **外链合规：** 付费合作必须披露并使用 sponsored/nofollow；不能把“可以买链接”当常规排名策略。
9. **内容维护：** Windows/macOS 权限、快捷键和产品套餐会变，至少季度复核。
