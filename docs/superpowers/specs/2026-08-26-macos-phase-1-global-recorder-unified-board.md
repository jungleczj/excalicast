# macOS 第一阶段：全局录制条与统一白板规格

> 状态：第一阶段已沟通细化，等待实施
> 日期：2026-08-26
> 适用产品：基于 Excalicast Web 的 macOS 客户端

## 1. 阶段目标

Mac App 冷启动、重启或登录完成后，首先显示全局紧凑录制条；白板默认隐藏。用户无需进入 Web `/app` 工作区，即可选择录制来源、开始基础录制，并通过全局快捷键在任意前台应用上召出同一块 Excalidraw 白板。停止录制后，媒体和白板事件安全落盘，应用自动进入该录制的导出界面。

第一阶段交付的是一个可实际使用、可打包演示的最小录屏产品闭环，不是窗口、IPC 或界面占位符。

## 3. 产品入口与窗口模型

### 3.1 冷启动

- 只显示独立、置顶、可移动的紧凑录制条。
- 白板、完整 Studio、导出编辑器、Camera 窗口和提词器均不得自动出现。
- 完整 Studio 是按需入口，不是录制前置页面。
- 登录完成后返回并聚焦当前安装版本的录制条，不得跳转到旧 Web `/app`、Production Site URL 或历史 Renderer。

### 3.2 全局录制条

默认紧凑态显示：

- 录制来源：显示器、应用、窗口、区域。
- 麦克风和系统音频真实状态。
- 白板入口。
- 开始录制；录制中切换为计时、暂停/继续、停止。
- 展开设置入口；设备和高级参数不挤入默认紧凑态。

录制条使用 Excalicast Web 的品牌颜色、字体、图标和组件语义，并借鉴 Screen Studio 的 Apple 式精细层级、圆角、阴影、间距和动效；不得复制 Screen Studio 品牌或把 Mac 做成另一套产品。

### 3.3 全局快捷键

默认使用可重绑定的 `Control + Option` 系列：

- `Control + Option + R`：显示/隐藏录制条。
- `Control + Option + B`：显示/隐藏白板。
- `Control + Option + P`：暂停/继续录制。
- `Control + Option + S`：停止并保存。

注册冲突必须在录制条中显示原因并允许重绑定；应用退出时必须释放快捷键。

## 4. 一个白板，而不是两种白板

### 4.1 单一场景

- 始终只有一个 Excalidraw scene、一份元素集合、一条 undo/redo 历史、一套文件资源和一份自动保存状态。
- 不创建独立的 `Ink scene` 和 `Board scene`，也不在切换时复制或迁移元素。
- 当前 scene 可在录制前、录制中和录制后继续编辑；录制项目保存当次事件流和引用的 scene 版本。

### 4.2 四个正交属性

白板表现由四组独立状态组成，不再使用互斥的 `Ink / Board` 产品模式：

1. **窗口形态**：`full-display` 或 `floating`。这是同一个窗口的几何预设。
2. **背景透明度**：`0%–100%` 连续调整；`0%` 得到透明 Ink，`100%` 得到完整白板。
3. **元素透明度**：笔迹和元素整体透明度独立于背景。
4. **交互状态**：`draw`、`pass-through` 或 `hidden`。

允许任意组合，例如：

- 全屏覆盖 + 背景 `0%`：在任意桌面应用上标注。
- 全屏覆盖 + 背景 `70%`：沉浸式讲解板。
- 浮动窗口 + 背景 `100%`：标准浮动白板。
- 浮动窗口 + 背景 `30%`：半透明便签式白板。

改变窗口形态、透明度或交互状态不得修改 Excalidraw 元素坐标、撤销历史或保存身份。

### 4.3 窗口行为

- 白板默认隐藏，通过快捷键或录制条召出。
- `full-display` 覆盖当前选定显示器；`floating` 可移动、resize、吸附安全边缘，并按显示器记忆位置与大小。
- 提供“一键恢复覆盖当前显示器”。
- 支持跨应用、多个 Space 和多个显示器；显示器断开时迁移到主显示器安全区。
- 白板窗口和工具条必须被 ScreenCaptureKit 排除；原始屏幕轨不得烘焙这些像素。
- `pass-through` 时用户可操作底层应用；必须保留全局快捷键恢复绘制或隐藏白板。

## 5. 工具体系

### 5.1 绘图工具

绘图能力全部来自仓库现有 `@excalidraw/excalidraw`，禁止维护第二套绘图模型。第一阶段必须保留：

- 选择、自由绘制、橡皮擦、撤销和重做。
- 矩形、椭圆、菱形、直线、箭头和文本。
- 图片、激光笔、缩放、颜色、线宽、填充、图层与文件资源。
- 完整 Excalidraw 工具面和素材库入口。

### 5.2 桌面控制工具

Excalicast 只增加 Excalidraw 之外的桌面壳控制：

- 背景透明度和元素透明度。
- 全屏覆盖/浮动窗口。
- 绘制/点击穿透/隐藏。
- 工具条拖动、折叠和完全隐藏。
- 自动保存、命名快照、打开、清空。

默认显示“精简常用工具条”，更多按钮打开完整 Excalidraw 工具面。精简按钮只是 Excalidraw API 的快捷入口，不能拥有另一份工具状态。

## 6. 白板保存与录制语义

- scene 变更自动保存；隐藏、切换窗口形态或重启 App 后恢复最后草稿。
- 用户可以创建命名快照、打开命名快照和明确清空当前 scene；清空必须二次确认且可通过 undo 恢复。
- 白板元素增量、文件、指针/激光、擦除、undo/redo、视口和透明度变化使用同一单调项目时钟记录。
- 录制暂停期间项目时间不推进；暂停中的编辑可保留在当前草稿，但只有恢复后按明确边界进入录制事件流。
- 预览和导出通过结构化事件重放白板，不能依赖捕获白板窗口像素。

## 7. 基础录制闭环

第一阶段范围内必须真实支持：

- 显示器、应用、窗口、区域来源。
- 麦克风与系统音频独立轨。
- 白板事件轨。
- 开始、暂停、继续、停止。
- 媒体和事件安全落盘、崩溃后可诊断恢复。
- Stop 后等待收尾完成并自动打开该录制的导出界面。

第一阶段不实现 AI Camera 自动布局、Auto Zoom 自动规划、智能跟读提词器、Director/ChatCut 自动素材或正式原生成片器；这些能力不得以假按钮、假预览或 `ready` 字段冒充完成。

## 9. 第一阶段验收与截图

必须至少提供以下真实产品截图，每完成一个可见步骤即回传用户确认：

1. 冷启动：只显示底部紧凑录制条，白板隐藏。
2. 快捷键召出：第三方应用上方显示全屏透明白板与左侧可移动工具条。
3. 透明 Ink：背景 `0%`，绘制、形状、文本、擦除和 undo 可用。
4. 连续过渡：同一 scene 从透明全屏调整为半透明，再切成浮动完整白板，内容和 undo 历史不变。
5. 点击穿透：笔迹仍可见，底层应用可操作；工具条隐藏后快捷键仍可恢复。
6. 基础录制：真实来源、mic、system audio、白板事件和计时状态可见。
7. 停止收尾：自动进入该录制的导出界面并可播放。
8. 重启恢复：录制条、白板草稿、窗口几何和命名快照恢复。

阶段通过条件：定向测试、Web/Desktop typecheck、相关 Swift contract、Web 回归、真实 packaged E2E、截图审阅、diff-check 和独立 fresh review 全部通过；否则不得进入第二阶段。
